# Brand Brief

**Product**: Checkpoint (Pending Approval)
**Category**: AI Agent Client / Developer Tool
**One-line definition**: A native iOS remote control that un-tethers developers from their desk by providing secure, tap-to-approve control over local AI coding agents.

**Primary audience**: Sophisticated engineers running local agent workflows who want to walk away from their desk.
**Secondary audience**: Tech leads reviewing agentic code generation.

**Primary problem**: Developers are physically tethered to their laptops to monitor and approve agent commands.

**Core value proposition**: Monitor, steer, and interact with your local AI coding agents from anywhere, transforming a messy CLI experience into a clean, mobile-native UI over a fully private connection.

**Primary differentiation**: Absolute privacy (direct Mac connection, zero telemetry) and Native iOS UX for abstract permissions.

**Brand promise**: You will always know exactly what your agent is doing, and you control its next step.

**Mission**: To un-tether software engineers from their desks by making autonomous coding observable and steerable from anywhere.

**Vision**: To become the default persistent mobile control plane for a developer's entire autonomous infrastructure.

**Product principles**:
1. Host is Truth.
2. Private by Default.
3. Structured over Streamed.
4. Resilient to Disconnects.
5. Capabilities are Earned.

**Brand personality**: Professional, Minimal, Technical but legible, Premium, Calm.

**Voice**: Direct, clear, unembellished. Like a senior engineer explaining a reliable system.

**Messaging pillars**:
1. Total Control, Zero Desk
2. Private by Design
3. Native Clarity

**Trust principles**:
- Verifiable local-only network traffic (Tailscale/SSH).
- Device-local keys.
- Explicit enablement required for destructive host access.

**Visual direction**:
- Muted, terminal-inspired dark modes with strict, highly visible semantic colors for permissions.
- High information density with comfortable padding.
- Fast, unblocked motion.

**Things the brand should NEVER feel like**:
- A generic cloud AI wrapper.
- A hype-driven startup.
- A chaotic SSH window.

**Approved terminology**: 
- Daemon, Agent, Host, Subagent, Client, Allow/Deny.

**Avoided terminology**: 
- Fully autonomous, Our servers, Set-and-forget, ChatGPT alternative.

**Current unresolved decisions**:
- Final canonical name approval (Checkpoint vs Claude Mobile).
- Future monetization strategy.
